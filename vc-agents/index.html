Deck Triage Agent

AI agent that triages inbound VC pitch decks against an investment thesis

VCs lose good deals and burn founder goodwill the same way: pitch decks pile up in an inbox and either sit unread or get skimmed inconsistently. This agent watches a deals inbox, extracts the full text of every incoming deck (handling multi-attachment emails correctly - it picks the actual deck, not just whatever file happened to be first), and runs it through an AI agent that scores it FIT / MAYBE / REJECT against a concrete investment thesis: stage, check size, target sectors, hard disqualifiers, and a real traction/team bar.

Every decision is logged to Postgres with full reasoning, posted to Slack for the team (with REJECTs correctly kept quiet), and every founder gets an honest, non-committal reply - so nobody ever emails a fund and hears nothing back. Built with explicit anti-hallucination guardrails: the model only ever reasons from the deck text actually given to it, low-text/corrupted decks are routed to a human instead of guessed at, and a prompt-injection guard stops a deck from talking the model into approving itself.

Demoed against "SaanVC," a fictitious early-stage fund I invented to give the agent a concrete, realistic investment thesis to work against - not a real client engagement.

Stack: n8n, Gmail API, OpenAI (GPT-4o-mini), PostgreSQL, Slack API, LangChain structured output parsing.
